# SQL Data Analysis Internship – Task 3 🚀

This repository contains **Task 3** of the SQL Data Analysis Internship, focused on **advanced SQL queries** using real-world analytical logic.

## 📂 Task Overview
In this task, we analyze student performance using:
- JOINs
- GROUP BY
- HAVING
- Subqueries
- Aggregation functions

## 🗂 Database Tables Used
- **Students** (student details)
- **Courses** (course information)
- **Enrollments** (student-course mapping with grades)

## ✅ Queries Implemented

1. **Top student per course**  
   - Finds the highest scorer in each course using subqueries.

2. **Pass rate per course (Grade ≥ 40)**  
   - Calculates percentage of students who passed each course.

3. **Overall topper across all courses**  
   - Identifies the best-performing student based on average marks.

4. **Students enrolled in multiple courses**  
   - Lists students registered in more than one course.
